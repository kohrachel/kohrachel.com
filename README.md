I really wanted a website that felt like it had a soul, and so far I think I really like this one :) Thanks for stopping by! Technical details below: 

Tech stack: 

- React + [Next.js](https://nextjs.org) project
- Supabase + Supabase Storage
- Drizzle ORM
- Misc: Bun (package manager), Tailwind CSS, ESLint, Prettier, Huge Icons, Shadcn (though honestly I don't really feel like I used Shadcn) 

Other software stuff: 

- Deployed on Vercel
- Domain from GoDaddy (moving to Cloudflare sometime December)
- A lot of help from Pinterest, Canva, Photopea. Couldn't have done it without you guys, not even joking

## Developing 

To be honest, I don't think anyone should be cloning this for their own website. Like I feel like I injected so much personality into this website (and I will continue to do so!) that it just feels a little weird if you're copying and pasting it for your website? I might make this repo private in the future for that reason. I'm currently keeping it public for resume/sharing purposes lol.

If you find this website cool, I really think you should make your own! Even if you don't think you can. I mean, I literally have two repositories of previous iterations of my blog that didn't live up to the vision I had. I'm not saying you won't fail, but I am saying that it's worth trying either way. Just try not to get lost in the nits. And remember to put some soul into your work
